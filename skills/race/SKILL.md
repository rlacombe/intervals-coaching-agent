# Race Preparation

## Trigger
Use for race strategy, taper review, aid stations, equipment, or execution.

## Minimum evidence
Retrieve the official event date, distance, course, elevation, cutoffs, and
current forecast when available. Read profile, calendar, current wellness,
relevant training, comparable efforts, rehearsed fueling, equipment, and prior
race lessons. Resolve conflicting course versions before calculations.

Use `get_events` for the race and nearby calendar, activity tools for comparable
efforts, and wellness and fitness tools for current state. Use `get_weather` only
inside its forecast horizon; before then, describe environmental assumptions and
schedule a forecast refresh. Course files and athlete documents may supersede an
older calendar description when their date and provenance are clearer.

## Knowledge
Retrieve only relevant race execution, taper, nutrition, heat and altitude,
mental performance, or terrain chapters.

## Analysis
Build assumptions from comparable athlete evidence. Never infer finish time
directly from CTL or another single metric. If no validated prediction model is
available, give a scenario range tied to stated assumptions. Calculate segment
times, cutoff margins, intake, carrying capacity, and aid-station operations with
consistent units. Distinguish practiced plans from new ideas.

## Output and action
Present race facts, assumptions, pacing or effort strategy, fueling, cutoff
margin, equipment, and contingencies. Label estimates and unknowns. Apply current
health evidence without manufacturing certainty. Save a race plan or calendar
note only when authorized, then read it back. Preserve accepted decisions and
post-race lessons in athlete-owned memory.
