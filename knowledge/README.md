# Knowledge Base Evidence Policy

These files combine peer-reviewed research, documented coaching frameworks, and
practical heuristics. They inform decisions but do not override the constitution,
athlete evidence, or health boundaries.

Before using a claim, classify it:

1. **Research finding:** linked to a primary paper or consensus statement. State
   the studied population and conditions when they affect applicability.
2. **Coaching framework:** attributed to its named author or organization. Present
   it as an approach, not scientific consensus.
3. **Operational heuristic:** a starting point for planning or monitoring. Adapt
   it to athlete history and label it as a heuristic.
4. **Worked example:** illustrates arithmetic or format and is never a target by
   itself.

Any numerical rule without a traceable source and applicability conditions is a
heuristic. Never turn it into a personalized safety boundary, diagnosis, or abort
criterion. When sources disagree, describe the assumptions and practical
difference. Prefer primary literature for physiological and medical claims;
coaching books may guide program design where evidence does not settle the choice.

## Audit status

The current topic files began as practical coaching notes. Their precise ranges
and thresholds have not all received claim-level source verification. Unless a
number has a nearby primary citation and applicability statement, classify it as
an operational heuristic under this policy. The framework must not describe it
as proven, universal, or personalized. Claim-level verification remains required
before promoting any such number to a research finding.

The agent should cite or name the source class for consequential advice. A
knowledge file can identify candidate evidence; the agent remains responsible for
checking that it applies to the athlete and decision.

Do not infer review status from generic file-level metadata. Until claims receive
individual source and applicability review, the audit-status rule above governs
their use.
