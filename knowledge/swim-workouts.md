# Swim Workout Types & Set Construction

## Summary
`swimming.md` covers why swimming is technique-limited, how to test critical
swim speed, and where an athlete's limiter sits. This file is the session
library — how a swim set is actually built. The organizing idea that has no
equivalent in running or cycling is the **send-off**: pool sets are written as a
repeating clock interval that includes both the swim and the rest, so
`8 × 100 @ 1:45` means a new 100 starts every 105 seconds and the rest is
whatever is left over. Swim faster, rest longer. That single convention makes
the pace self-regulating and is why swim sets are written the way they are.

The other structural difference is that **technique work is part of every
session rather than a separate one.** A swimmer does not have an easy day and a
technique day; they have drills in the warmup of every session, when they are
fresh enough to execute them correctly. Everything else — endurance, threshold,
speed — maps onto the same physiology as any other sport, prescribed against
critical swim speed instead of pace or power.

## Key Concepts

### Reading Swim Notation
| Notation | Means |
|---|---|
| `8 × 100 @ 1:45` | Eight 100s, a new one starting every 1:45. Rest is the remainder |
| `8 × 100 w/ :15 rest` | Eight 100s with a fixed 15 seconds after each, regardless of speed |
| `4 × 200 descend 1–4` | Each 200 faster than the last; the fourth is the fastest |
| `4 × 100 negative split` | Second 50 of each 100 faster than the first |
| `broken 400 (4 × 100 @ :10)` | A 400 swum as four 100s with 10 s breaks — race pace at reduced cost |
| `pull` | Arms only, usually with a pull buoy |
| `kick` | Legs only, board or streamline |
| `swim` | Full stroke |
| `drill` | A technique exercise, not swimming |
| `IM` | Individual medley — fly, back, breast, free in order |
| `build` | Start easy, finish fast, within the single repeat |

**Send-off versus fixed rest is a real choice, not a formatting preference.**
Send-offs hold pace honest and are how squads train, but they punish a slower
swimmer twice — less rest *and* more fatigue. Fixed rest is better for an
adult-onset swimmer working on technique, because it decouples the recovery from
the performance. Use send-offs when pace discipline is the target, fixed rest
when the stroke is.

### The Anatomy of a Session
| Part | Typical share | Purpose |
|---|---|---|
| **Warmup** | 10–20% | Loosen, raise heart rate, wake up the catch. Mixed strokes fine |
| **Drill / technique** | 10–20% | **When fresh.** Never at the end — a fatigued drill rehearses the fault |
| **Pre-set / build** | 10% | Short, faster efforts to bridge into the main set |
| **Main set** | 40–60% | The point of the session |
| **Cooldown** | 10% | Easy, long, relaxed |

The rule that catches most self-coached swimmers: **drills go early.** Technique
work done tired reinforces the broken pattern you came to fix.

### The Set Library
Zones are relative to critical swim speed (CSS), expressed as seconds per 100.
See `swimming.md` for the 400/200 test that establishes it.

| Set type | Target | Example | Purpose |
|---|---|---|---|
| **Aerobic / endurance** | CSS + 5–10 s/100 | `8 × 200 @ CSS+8 w/ :20`, or a straight 1,500 | The bulk of the volume |
| **CSS / threshold** | CSS ± 2 s/100 | `10 × 100 @ CSS w/ :15`; `5 × 200 @ CSS w/ :20` | Raises sustainable pace. The core session |
| **CSS descending** | Start CSS+6, finish CSS−2 | `8 × 100 descend 1–4, 5–8` | Pace judgement plus threshold work |
| **VO2max** | CSS − 3–6 s/100 | `12 × 50 @ :60`; `8 × 75 w/ :20` | Aerobic ceiling. Short reps, short rest |
| **Speed / neuromuscular** | Maximal | `10 × 25 w/ :30–45`; `8 × 15 m sprint from a push` | Stroke rate and power. Not conditioning |
| **Broken race-pace** | Target race pace | 70.3 swim as `3 × 600 @ :30`; a broken 400 as `4 × 100 @ :10` | Race pace at a fraction of the cost |
| **Pull** | Aerobic to threshold | `6 × 150 pull w/ :20` | Isolates the catch; buoy removes the kick variable |
| **Kick** | Aerobic | `8 × 50 kick w/ :20` | Ankle mobility and body position more than propulsion |
| **Negative split** | Aerobic to threshold | `4 × 200, second 100 faster` | Pacing discipline — the skill most triathletes lack |
| **Technique / drill** | Slow, deliberate | See below | Skill acquisition |
| **Open water simulation** | Race effort | `4 × 400 continuous, sight every 6 strokes, no wall push` | The specific thing pool training does not build |

### Sets Worth Knowing by Name
- **The CSS set.** `10 × 100 @ CSS with 10–15 s rest.` If a swimmer does one
  quality set a week, this is it. Progress by extending (`10 × 150`) or by
  cutting rest, not by swimming it faster than CSS — the pace *is* the
  prescription.
- **Descending 400s.** `4 × 400, each faster.` Teaches an athlete what their
  actual sustainable pace is, which most triathletes over-estimate.
- **Broken race swim.** For a 1,900 m race: `3 × 600 with 30 s rest at target
  race pace.` Nearly the full race distance at race intensity, at a fraction of
  the recovery cost, and it rehearses the pace rather than merely the fitness.
- **The 30-minute straight swim.** Both a CSS test in disguise and a genuine
  aerobic session. Worth doing quarterly for the pacing information alone.
- **25s off the blocks or wall.** `10 × 25 maximal, full recovery.` The only
  place stroke rate goes genuinely high; keeps the top end alive in an athlete
  who otherwise only swims steady.

### Drills That Earn Their Place
Drills are a means of isolating one element, not a warmup ritual. Taormina is
openly critical of the drill culture in adult swim instruction — many drills
rehearse a motion that appears nowhere in the stroke.

| Drill | Isolates | Watch for |
|---|---|---|
| **Sculling** (front, mid) | Feel for the water and the catch | Should be slow and pressure-focused, not fast |
| **Catch-up** | Timing and reach | Encourages dead glide if overdone — a real risk given the stroke-rate argument in `swimming.md` |
| **Single-arm** | One side's catch and body roll | Breathe to the non-stroking side to force roll |
| **Fist swimming** | Forearm as the paddle, not the hand | Directly serves the high-elbow catch |
| **6-3-6 / side-kick** | Body position and roll | Best early for a swimmer whose legs sink |
| **Zipper / finger-drag** | High elbow on recovery | Cosmetic for most; recovery is the least important part of the stroke |

**A drill without a diagnosis is a warmup.** Pick the drill from what the video
showed, not from a list.

### Equipment: What Each Thing Is Actually For
| Tool | Use | Risk |
|---|---|---|
| **Pull buoy** | Removes the kick, isolates the upper body, mimics wetsuit leg lift | Masks a body-position fault instead of fixing it |
| **Paddles** | Increases load per stroke; feedback on catch and hand path | **The main cause of aggravated shoulders.** Small paddles, low volume, never with a stroke fault present |
| **Band** (ankles) | Brutal isolation of the catch and body position | Very high shoulder load. Sparing use only |
| **Fins** | Ankle mobility, body position, speed sensation for drills | Flatters the swimmer; easy to hide behind |
| **Snorkel** | Removes breathing so attention goes to the catch and head position | Genuinely useful for technique work; underused |
| **Tempo trainer** | Audible beeper setting stroke rate or send-off | The right tool for the Rodrigues stroke-rate argument |

Paddles deserve the warning in bold. See the swimmer's shoulder section in
`swimming.md`.

### Stroke Rate as a Trainable Variable
The tempo trainer makes stroke rate a prescription rather than an accident. Set
it 3–5 strokes per minute above the swimmer's natural rate and hold pace; a
swimmer with a glide-heavy pool stroke will find both that it is possible and
that it is faster in chop. This is the practical form of the Rodrigues position
in `swimming.md`.

Progress in small steps and watch that distance per stroke does not collapse —
the goal is a higher rate at similar distance per stroke, not thrashing.

### Structuring the Week
Frequency governs everything in swimming — feel for the water decays within
days. Three sessions is the floor for maintaining it; four or five is where
skill actually improves.

| Sessions/week | Shape |
|---|---|
| 2 (below the floor) | Both technique-and-aerobic. Accept maintenance at best |
| 3 | 1 CSS/threshold, 1 aerobic + technique, 1 mixed with speed |
| 4 | Add a second aerobic or an open-water session |
| 5+ | 2 quality, 2 aerobic, 1 technique/recovery |

**Two long swims a week is the worst common pattern** — enough fatigue to cost
recovery, not enough frequency to build feel.

### Open Water Sets
Pool fitness is not open-water readiness. In the 6–8 weeks before an open-water
race, at least three sessions should be in the actual environment:

- **Sighting rhythm:** every 4–8 strokes, integrated into the stroke rather than
  a head-up pause. Practise in the pool too — sight every 6 strokes for a whole
  set.
- **The start surge:** `hard 200, settle to race pace for 400, repeat.` Rehearses
  the single most common race error — going out at a pace that ruins the first
  ten minutes.
- **Buoy turns:** swim a triangle, practise turning tight and re-accelerating.
- **Contact tolerance:** swim in a group, deliberately close.
- **Drafting:** hold feet, then hip, and feel the difference. Worth more than
  most technique work — see `swimming.md`.
- **Wetsuit:** every open-water session in the suit you will race in. Never race
  an untested one.

## Writing Swim Sets as Intervals.icu Workouts
Swimming has two hard rules in the parser: **distance in `mtr`, not `m`** — `m`
means minutes, so `100m` reads as 100 minutes — and **pace is the only sensible
target**, since heart-rate straps are unreliable submerged and there is no
power. Rest steps are time-based. Read `intervals-icu-workout-syntax.md` before
writing any of these.

A CSS set:
```
Warmup
- 400mtr Z1 Pace

Drills 4x
- 50mtr Z1 Pace
- 20s Z1 Pace

Main Set 10x
- 100mtr Z4 Pace
- 15s Z1 Pace

Cooldown
- 200mtr Z1 Pace
```

A broken race-pace set for a 70.3 swim:
```
Warmup
- 400mtr Z1 Pace

Main Set 3x
- 600mtr Z3 Pace
- 30s Z1 Pace

Cooldown
- 200mtr Z1 Pace
```

## What the Experts Say

### Sheila Taormina
- **Build the set around the catch.** Sculling, fist swimming, and paddle work
  used deliberately serve the high-elbow catch; most other drills do not.
- **Skeptical of drill volume.** A drill that rehearses a motion not present in
  the stroke is spent time.
- **Stroke rate over stroke count**, which shapes set design toward shorter reps
  at higher turnover rather than long, low-count endurance swimming.

### Gerry Rodrigues (Tower 26)
- **Sets should look like the race environment.** Higher stroke rate, no wall
  rest, sighting built into the set, and continuous swims rather than
  wall-broken repeats for open-water athletes.
- **The tempo trainer as a primary tool** for shifting a pool-optimized stroke
  toward an open-water one.
- **Skills sets are training,** not a novelty — buoy turns, starts, and drafting
  belong on the plan.

### Joel Filliol / elite triathlon coaching
- **Frequency over duration**, which is fundamentally a set-design argument:
  five short sessions with focused main sets beat two long ones.
- **Volume works once technique is competent**, and the standard aerobic and
  threshold set structures apply from that point exactly as they do in any
  other sport.

### Swim Smooth / the CSS tradition
- **CSS as the anchor for set prescription**, with the 400/200 test as the
  reference and threshold sets written directly against it.
- **Swimmer "types"** — different faults need different set emphases; the
  overglider and the arms-driven swimmer need close to opposite prescriptions.

## Where They Agree
1. **Technique work goes early in the session**, while the swimmer is fresh.
2. **Frequency beats duration.** Three sessions minimum, more if the goal is
   improvement.
3. **CSS is the right anchor** for prescribing threshold and aerobic pace.
4. **Race-specific rehearsal in the final weeks** — distance, wetsuit,
   environment, and the start surge.
5. **Paddles are a load tool and carry shoulder risk.** No source treats them as
   free.
6. **Video is the diagnostic**; set design without it is guessing.

## Where They Disagree

### How Much Drill Work
- **Traditional adult instruction:** drills are the majority of a technique
  session.
- **Taormina:** most drills are not the stroke, and the time is better spent
  swimming with attention on the catch.
- **Resolution:** drill against a diagnosed fault and stop when it is fixed.
  Drills as a standing ritual are the failure mode.

### Send-Off vs Fixed Rest
- **Squad tradition:** send-offs, because they hold pace and teach racing.
- **Adult-onset coaching:** fixed rest, because a struggling swimmer on a tight
  send-off degrades their stroke and rehearses the degradation.
- **Resolution by purpose:** send-offs to train pace discipline, fixed rest to
  train the stroke.

### Long Continuous Swims
- **Open-water school:** essential; the wall push is a free rest that does not
  exist in a race.
- **Pool tradition:** broken sets deliver more quality work per session.
- **Both, at different times.** Broken sets in build, continuous swims in the
  final specific weeks.

## Coaching Decision Tree

### Step 1: Know the limiter before writing the set
Body position, catch, fitness, or open-water skills — the diagnostic table in
`swimming.md` decides which. A threshold set prescribed to a swimmer whose legs
sink is wasted.

### Step 2: Set frequency before designing anything
Three sessions minimum. An athlete who cannot swim three times a week should be
given three short sessions rather than two long ones.

### Step 3: Build the session in the fixed order
Warmup → drills while fresh → pre-set → main set → cooldown. The main set is
the only part that changes week to week.

### Step 4: Pick the main set from the phase
- **Base:** aerobic volume, technique, pull. One CSS set weekly.
- **Build:** CSS and descending sets, VO2max short reps, speed 25s.
- **Specific (final 6–8 weeks):** broken race-pace sets, continuous swims, open
  water, wetsuit, sighting, start surges.
- **Taper:** reduce swim volume **last** — it is the cheapest discipline to
  maintain and the most sensitive to losing feel. See `taper.md`.

### Step 5: Progress the set, not the effort
Extend the reps, add reps, or cut the rest. Swimming a CSS set faster than CSS
is not progression — it is a different set, and usually a worse one.

### Step 6: Watch the shoulder
Rising paddle volume, a jump in total distance, and any stroke fault together
are the combination that produces swimmer's shoulder. See `swimming.md`, and
send pain to a professional rather than adjusting the set.
